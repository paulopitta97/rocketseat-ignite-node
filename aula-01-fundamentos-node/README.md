# 🚀 Aula 01 – Fundamentos do Node.js

Este projeto foi desenvolvido durante a trilha Ignite da Rocketseat e tem como objetivo apresentar os **fundamentos do Node.js**, incluindo:

- Conceitos básicos do runtime Node.js
- Manipulação de rotas HTTP sem frameworks
- Trabalhando com JSON e Streams
- Entendendo o funcionamento do `req` e `res`

## 📁 Estrutura

O projeto contém um pequeno servidor Node.js criado com:

- `http` nativo
- Manipulação de dados em memória
- Rotas básicas (`GET`, `POST`, `PUT`, `DELETE`)

## 🔧 Instalações

- HTTPie (Chocolatey)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/paulopitta97/rocketseat-ignite-node.git
cd rocketseat-ignite-node/aula-01-fundamentos-node
```

2. Inicie o servidor:

```bash
node src/server.js
```
